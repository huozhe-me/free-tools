# Free Tools

A collection of small browser-based utilities.

## A-Z Letter Card Maker

A lightweight printable A-Z alphabet card generator for children's learning cards.

Features:
- A-Z card set preloaded with simple toddler-friendly words
- Edit letter, English word, Chinese label and sentence
- Upload a local image for each card
- Choose simple / soft / pastel visual themes
- Preview cards in a grid
- Print directly from the browser
- Export/import card data as JSON
- Autosave to localStorage

Open `index.html` directly in a browser, or serve the repository with any static web server.
